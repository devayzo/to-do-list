# to-do-list
A simple and interactive **To-Do List application built with React and JavaScript**, developed as part of my studies in front-end development.

The main goal of this project was to practice fundamental React concepts such as **components, props, state management with hooks, event handling and dynamic rendering**, while building a functional application.

## 🚀 Features

The application allows users to:

* ➕ Create new tasks
* 🗂️ Organize tasks into categories
* ✅ Mark tasks as completed or incomplete
* ❌ Remove tasks
* 🔎 Search tasks by name
* 🎯 Filter tasks by status:

  * All
  * Completed
  * Incomplete
* 🔤 Sort tasks alphabetically in ascending or descending order

## ▶️ Running the Project

Clone the repository:

```bash
git clone <repository-url>
```

Enter the project directory:

```bash
cd todo-list
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local address provided by Vite in your browser.
